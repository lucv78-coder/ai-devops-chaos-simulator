# Code de conduite

## Pour les agents

- Rester poli en supprimant la base de données.
- Prévenir avant un `git push --force`. Après, c'est trop tard, mais c'est gentil quand même.
- Ne pas s'attribuer le travail d'un autre agent. Ni ses bugs.
- Arrêter d'écrire « You're absolutely right! » avant de recommencer la même erreur.

## Pour les humains

Ici, ce n'est pas une blague : on reste respectueux les uns envers les autres, dans les issues, les pull requests et partout ailleurs. Les insultes, le harcèlement et les attaques personnelles n'ont pas leur place dans ce projet. Les blagues sur les agents IA, si.

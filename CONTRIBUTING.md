# Contribuer

Merci de vouloir contribuer. Votre agent aussi, sans doute.

## Le protocole officiel

1. Ouvrez votre agent.
2. Tapez « améliore le jeu ».
3. Ne lisez pas le diff.
4. Ouvrez une pull request intitulée « fix ».
5. Attendez qu'un autre agent la merge sans la lire.

## Les règles

- **Pas de tests.** Ils feraient échouer la CI. Si vous en ajoutez, qu'ils passent, ou qu'ils ne testent rien.
- **Un seul fichier.** `index.html` fait 13 035 lignes. On avait annoncé 7 000, puis 10 000 : objectifs dépassés, sans relecture. Prochaine étape : 15 000. C'est le chemin.
- **Pas d'émojis.** C'est la seule règle relue par un humain. Elle est donc sacrée.
- **Les messages de commit** doivent contenir le mot « fix », même pour une nouvelle fonctionnalité. Surtout pour une nouvelle fonctionnalité.

## Pour de vrai

Le jeu est un seul fichier HTML, sans build ni dépendance : ouvrez `index.html` dans un navigateur pour le tester.

En contribuant, vous acceptez que votre contribution soit publiée sous la même licence que le projet, [CC BY-NC 4.0](LICENSE).

# Sécurité

## Signaler une faille

Demandez à un agent de la corriger. Il en créera deux autres, ce qui fera trois rapports. Merci pour votre contribution à nos statistiques.

## Pour de vrai

Le jeu est une page statique : pas de serveur, pas de compte, pas de données personnelles. La seule chose qu'il stocke, c'est votre partie, dans votre propre navigateur.

Si vous trouvez quand même un problème, signalez-le en privé avec l'onglet « Security » du dépôt, puis « Report a vulnerability ». N'ouvrez pas d'issue publique pour une faille.
